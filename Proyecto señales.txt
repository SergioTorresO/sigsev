Quiero desarrollar una aplicación web profesional, moderna y escalable enfocada en la gestión de señalización vial para tránsito, orientada al control y visualización de señales de tránsito en zonas urbanas y rurales.

El sistema debe funcionar como una plataforma inteligente de gestión vial utilizada por alcaldías, secretarías de tránsito y operadores de movilidad.

OBJETIVO PRINCIPAL:
Crear un sistema web capaz de registrar, visualizar, administrar y monitorear todas las las señales de tránsito del casco urbano y rural mediante mapas interactivos, paneles administrativos y herramientas de inspección técnica.

REQUISITOS GENERALES:
- Diseño moderno y profesional
- Responsive (PC, tablet y móvil)
- Arquitectura escalable
- Seguridad robusta
- Interfaz intuitiva
- Optimizado para rendimiento
- Código limpio y modular
